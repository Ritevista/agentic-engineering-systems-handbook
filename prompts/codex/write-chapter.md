# Write Chapter Prompt Template

Write exactly one field manual chapter for this repository.

Inputs:
- Chapter file path: `<chapter-path>`
- Chapter title: `<chapter-title>`

Requirements:
- Keep a practical, architectural, reference-oriented tone.

8. Anti-patterns
