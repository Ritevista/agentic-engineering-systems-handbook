# References Management

This folder defines how external references are used in the **Agentic Engineering Field Manual**.

## Purpose
- Keep tool-specific claims anchored to verifiable sources.
- Prefer official documentation, standards, and primary references.
- Prevent accidental plagiarism and unclear attribution.

## How references are used
- `bibliography.md`: curated source catalog used across chapters.
- `source-notes.md`: chapter-level guidance for separating sourced facts from original analysis.
- `licenses.md`: tracking for reused/adapted external material and attribution obligations.

## Authoring expectations
- Use external sources for factual claims and behavior details.
- Do not copy long passages from external documentation.
- Use short quotes only when necessary.
- Paraphrase in original wording and link to sources.
- Add chapter-end **References and Further Reading** for tool-centric chapters.
- If adapting diagrams, tables, examples, snippets, or text, record provenance and license in `licenses.md`.
